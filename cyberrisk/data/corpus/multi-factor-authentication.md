# Multi-Factor Authentication Standard (synthetic guidance)

All remote access and every administrative account must use multi-factor authentication. Phishing-resistant methods such as hardware security keys are preferred over one-time codes sent by text message.

Service accounts that cannot use interactive factors must use short-lived credentials, restricted source networks and monitored secrets storage. Shared accounts are not permitted for privileged access.

Authentication logs are retained for one year. Repeated failed logins, impossible travel and sign-ins from unfamiliar devices raise an alert for the security analyst on duty.
